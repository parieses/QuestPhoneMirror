态二 · 投屏中 — 配对码成为 hero，警告内联

关键变化对照

① 卡片泛滥 → hairline 分区

原 7 张 20dp 圆角大卡（且卡内嵌卡）全部拆除。屏幕按「投屏设置 / 接收端」两个语义分区平铺，区间仅一条 1px 分隔线，唯一保留的容器是配对码 hero 块。

② 紫渐变主按钮 → cyan 实底

主按钮从「indigo→violet 渐变」改为 cyan 实底 + 深青字，是全屏唯一实色块， Squint test 下第一眼落点。按压态 cyan-deep。

③ RadioGroup → 分段控件

画质三档从系统 RadioButton 改为 iOS 风分段控件：surface-2 底、选中段 cyan 描边 + 12% cyan 底。与设计语言同源，一行占位更窄。

④ 配对码 hero 化

42sp 等宽 tabular 数字、0.22em 字距、青色，独立容器承载——从「状态栏里的一串字符」升格为投屏中的视觉主角，与「不一致」问题同步根治（唯一展示位）。

⑤ 设置行统一

防息屏 / 连接管理 / 文件共享统一为「标题 + 副标题 + 右侧控件」60dp 行；文件授权从整卡 + 大按钮降为行内 ghost 按钮。

⑥ 无障碍警告内联

原「覆写状态栏文案 + 独立大按钮」双入口，改为配对码卡内一条 amber 警告行，未开启才出现，整行可点跳系统设置。
