Features

为什么做这个

戴着头显时不想摘下来看手机——官方只支持头显投到手机，反过来没有现成方案。

实时镜像 · 画质三档

1080p30 H.264 硬编硬解，流畅 4M / 均衡 6M / 高清 10M 三档码率，弱网切流畅即用。

自动发现 · 免密直连

UDP 广播打开即连，不用输 IP。局域网只有一个发送端时无需配对码直接出画面。

配对码 · 连接管理

每次投屏 6 位随机码；发送端可扫描局域网接收端列表，勾选放行、踢人即时生效。

反向控制

点击、拖动、文字输入、Home / 返回 / 多任务，走无障碍手势，全机型免 root。

文件互传

接收端浏览发送端共享存储：图片 / 文本应用内预览，其他文件分片下载到本机。

方向同步 · 旋转适配

手机横竖屏切换后自动重建画布并通知接收端重排，画面不压扁、触摸映射不错位。

加密通道

连接先 ECDH 密钥交换，帧体 AES-256-GCM 加密，防局域网嗅探；旧版本自动回落明文。

文件推送

接收端选本机文件一键推送到发送端共享存储，64KB 分片、进度可见、成功回显路径。

投屏统计浮窗

接收端一键开浮窗，实时显示分辨率 / 帧率 / 码率 / 丢帧 / 解码帧率，卡顿时先降画质。

投屏保活 · 防息屏

投屏期间自动禁用系统熄屏，退出恢复原值；两端常亮，不用盯着屏幕防它黑掉。

检查更新 · 多源下载加速

入口页一键检查 GitHub Releases 最新版，弹窗展示更新说明，下载完成自动拉起系统安装。下载走多源候选链——Gitee 镜像 → 加速代理 → GitHub 直连，自动探测选可用源，国内更新不再干等；装过的版本不再打扰，下载中途离开页面回来会补提示。

How it works

工作原理

一条 TCP 连接双向复用，一路视频上行、一路控制下行。

两端只走局域网：UDP 45555 双 beacon（发送端宣告 + 接收端宣告），TCP 45556 单连接双向复用，不上传任何数据到公网。
Getting started

四步上手

首次配置约 5 分钟，之后打开即连。

手机 · 发送端

安装并授权

  1. 装 APK（Releases 里的 app-release.apk，与 App 内检查更新同签名）—— 直接装，无需任何额外设置
  2. 打开 App →「我是发送端」→ 点开始投屏，授予录屏权限
  3. 页面显示 6 位配对码；点「开启控制权限（无障碍）」，在系统设置里启用「QPM 控制服务」
  4. 保持 App 在前台，并在系统设置里允许其后台运行
第 3 步是关键：不开无障碍，接收端那边只能看、不能操作手机。局域网只有一台发送端时，接收端可免配对码直连。
Quest · 侧载

开发者模式侧载

  1. 浏览器打开 developer.oculus.com 建一个组织（免费）
  2. 手机 Meta Horizon app → 设备 → 打开开发者模式
  3. USB 连 Quest，头显内弹窗点允许 USB 调试
  4. adb install -r app-release.apk，然后在「资料库 → 未知来源」里启动
侧载应用不会出现在 Quest 主页桌面，这是 Meta 的机制，不是安装失败。接收端也可以是任意 Android 手机/平板（直接装同一 APK），或按 README 协议文档实现的电脑端。
FAQ

常见问题

Quest 里找不到刚装的 App？

侧载应用按 Meta 设计不出现在主页桌面。头显内进「资料库 → 右上角筛选 → 未知来源」即可找到。

接收端一定要 Quest 吗？能投到电脑或其他手机？

不限定。接收端可以是 Quest 2/3/3S/Pro、任意 Android 7.0+ 手机或平板（装同一 APK 选「我是接收端」），也可以是任何按 README 协议文档实现的电脑端——协议完全开放，约 150 行即可对接。

配对码是什么？每次都要输吗？

每次点「开始投屏」会生成新的 6 位随机码，接收端输入正确才开始推流。局域网内只有一台发送端时自动免密直连、无需输入；检测到多个发送端才需要选设备 + 输码。

有多台 Quest / 手机同时连着，怎么管理？

打开发送端页面的「连接管理」→「扫描接收端」，会列出局域网内所有接收端（设备名 + IP + 连接状态），勾选即放行；取消勾选会立即断开该设备，对方收到提示，重新勾选即恢复。

连上了但只能看，点不动手机？

手机端没开无障碍权限。去发送端页点「开启控制权限（无障碍）」，在系统设置里启用「QPM 控制服务」。

接收端一直搜不到发送端？

确认两端连同一路由器同一网段；路由器若开了 AP 隔离或手机开热点，都会阻断 UDP 广播。

画面花屏、绿屏？

等约 1 秒让关键帧到达即可恢复；仍有问题就退出接收端重进（接入时会强制请求关键帧）。

Netflix 等 App 投过去是黑的？

DRM 硬件保护内容禁止被捕获，这是 Android 的硬性限制，任何同类工具都无法绕过。

延迟大概多少？能玩游戏用吗？

局域网内硬编硬解端到端约 40–90ms，看通知、回消息、演示操作都够用；不适用于对帧率敏感的竞技场景。

接收端能看发送机的文件吗？

能。先在发送端页面点「授予文件访问权限」，接收端左下角「📁 文件」即可浏览共享存储：图片和文本直接预览，其他文件下载到本机。文件传输走独立连接、独立配对，不与视频抢带宽。

怎么更新到最新版？下载慢怎么办？

打开 App 入口页底部「检查更新」，有新版本会弹窗展示更新说明，点「下载并安装」即可，完成后自动拉起系统安装。下载走多源候选链（Gitee 镜像 → 加速代理 → GitHub 直连），自动探测选可用源，国内速度明显快于直连 GitHub；下载中途离开页面，回来会补提示安装。若提示「签名不一致」（早期装的是 debug 包），卸载后装 Releases 里的 app-release.apk 即可，App 无持久数据、卸载无损失。

Limitations

已知限制

手机熄屏即断，已提供防息屏开关缓解 DRM 内容（Netflix 等）黑屏 控制器 / 触摸 / 鼠标均为单指针，暂无双指缩放 Quest 端是 2D 面板，非 VR 原生悬浮面板 控制通道零鉴权，仅限可信局域网 Android 10 发送端受 scoped storage 限制，文件可访问范围收窄
